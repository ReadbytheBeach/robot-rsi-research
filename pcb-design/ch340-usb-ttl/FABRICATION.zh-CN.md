# 制板与装配要求（Rev A）

本文件必须与本次同版本 Gerber／钻孔文件一起交给板厂。不要只按文件默认值忽略阻抗要求。

| 项目 | 要求 |
|---|---|
| 外形 | 30×30mm，按 Edge.Cuts／GKO 轮廓中心线加工 |
| 层数 | 2 层 |
| 成品厚度 | 1.0mm；常规厚度公差需板厂确认 |
| 铜厚 | 按成品 35µm／1oz 设计，实际电镀后铜厚需用于阻抗复核 |
| 表面处理 | 默认沉金 ENIG；如需替换工艺，先核对细间距连接器焊盘平整度 |
| 阻焊／字符 | 绿色阻焊、白色顶层字符；不在焊盘上覆盖字符 |
| 装配面 | 仅顶面；Type-C 的机械焊脚／孔不代表底面放置元件 |
| 最小线路／间距设计规则 | 0.15mm／0.15mm |
| 通孔过孔 | 常规 0.60／0.30mm；局部 USB 换向焊盘合并用较小过孔，以钻孔文件为准 |
| 孔到铜设计规则 | 最小 0.15mm；Type-C 标准封装内部 NPTH 近铜约 0.194mm，板厂需确认接单能力 |
| 阻抗 | USB 数据主差分线目标 90Ω，建议控制 ±10% |

## 阻抗单独确认

名义叠层从上到下为：顶层阻焊 0.010mm、顶层铜 0.035mm、FR-4 芯板 0.910mm、底层铜 0.035mm、底层阻焊 0.010mm，总计 1.000mm；实际成品与阻焊厚度公差由板厂确认。

计算采用 εr＝4.2、介质 0.910mm、铜 0.035mm，主差分段线宽 0.750mm、边到边线隙 0.150mm。阻焊和附近顶层地铜会影响实际阻抗；均匀主段与连接器／ESD／IC 焊盘过渡应区别处理。

板厂需按实际材料、压合、铜厚与阻焊复核，提供所用叠层及阻抗 coupon／TDR 结果或可实现性确认。若需要调整线路几何，应返回修改设计文件后重新导出，不应在未沟通的情况下只修改 Gerber 中局部铜形。

底层在 USB 主差分段下保持地参考；不要因自行修改其他走线而切割这段参考面。

## 采购与装配确认

- U1 必须为 CH340C 内置时钟型号；CH340G 需要晶振，不能直接代换。
- J1 为 GCT USB4105-GF-A，J2 为 JST SM04B-SURS-TF(LF)(SN)，如替换必须核对厂家图、焊盘和壳体定位孔。
- J2 的 pin1＝3.3V、pin2＝TX、pin3＝RX、pin4＝GND；以焊盘编号与 pin1 标记为准。
- 本 BOM 中 4 个测试点是 PCB 铜焊盘，不采购、不贴装。
- 连接器与 PTC 的独立厂家机械 PDF 当前未完整取得；采用 KiCad 官方标准封装，投板前应与实际采购料核对。
- 首板验证见 `BRINGUP.zh-CN.md`；当前没有实物或电气性能实测结论。
