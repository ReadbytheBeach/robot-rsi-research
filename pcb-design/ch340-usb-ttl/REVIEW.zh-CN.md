# CH340C Type-C 转 3.3V TTL 设计审查

审查日期：2026-11-10。工具：KiCad 9.0.2、KiCad Happy（固定提交 `7d9d4d9fef87ac2d3eb16cfc5cdc9a0869f417f4`）、ngspice 44.2。

最终工程通过原生 ERC、DRC、未连接及原理图／PCB 一致性检查，全部布通。它可作为首板验证版交付；下单前仍需板厂确认阻抗叠层，并核对所采购连接器的厂家尺寸图。尚未进行实物 USB、负载、EMC 或阻抗测量。

审查对应 PCB SHA256：`9ac74752e29d6ac9b059adce91488045cf2fb2edac3b8ee5d9ea079dbe92c84f`。源文件哈希记录在 `analysis/review/layout-manual.json`，制造来源见 `analysis/fabrication-export.json`。

## 重点结论与使用条件

| 级别 | 项目 | 处理／边界 |
|---|---|---|
| 制造条件 | USB 90Ω | 均匀干线名义估算 89.859Ω，板厂需按实际叠层确认。器件焊盘、换向分支与窄线过渡另计；计算值不是整条线路的实测阻抗。 |
| 警告 | 连接器与 PTC 的独立资料缺口 | J1、J2、F1 使用明确 MPN 和官方 KiCad 封装；厂家机械 PDF 未完整取得。采购前核对实际型号尺寸、pin1 与连接器朝向。 |
| 警告 | USB 挂起功耗 | 3.3V 输出与指示灯没有挂起门控，不能据此宣称满足完整 USB 挂起电流要求。 |
| 警告 | UART_TX 局部参考地覆盖 | 工具的 29 个采样点有 2 个缺少对面参考地，保留 GP-001 提示；这不是 USB 均匀干线的地缺口。首板检查 UART 波形与外接线缆噪声，后续可继续改善局部回流。 |
| 使用条件 | 外供 3.3V ≤50mA | 这是使用预算，不是独立电子限流值；AP2112 的 600mA 额定值不代表主机授权电流。 |
| 使用条件 | 禁止电源反灌 | J2 pin1 是输出。目标独立供电时核对是否连接它；USB 断开后，目标 TX 应高阻／断开，或另加断电隔离，避免从本板 RX 反灌。 |
| 使用条件 | 仅 3.3V TTL | TX／RX 以本板方向命名，交叉接目标。没有 RS-232 电平转换，也没有 UART 断电隔离或硬件流控。 |

- **CH340C**：[WCH 官方仓库资料包](https://github.com/openwch/ch34x/blob/57b906d53a0ba95ea93fac8b75a752fbf43f548c/CH34XDS_EN.zip)中的 `CH340DS1_EN_3A_211224.pdf`，本地存于 `datasheets/`。来源、SHA256、逐脚表见 `datasheets/CH340C-source-and-pinout.json`。
- **AP2112**：Diodes 原厂文档 DS39724 Rev.2-2，2017-06；已检查镜像 PDF 的标题、管脚图与正文。下载地址及 SHA256 见 `datasheets/verified-mirror-sources.json`。
- **USBLC6-2**：ST 原厂文档 DS4260 Rev.7，2021-12；镜像来源及 SHA256 同上。
- **JST／GCT／PTC**：有明确采购型号和官方 KiCad 封装依据，但未取得独立厂家 PDF，不能将库内一致性称为厂家尺寸核验。
- 没有经评分的 `datasheets/extracted/` 结构化提取缓存；关键 IC 采用直接读取 PDF 的人工核对。

## 本轮变化

这是该设计首版，没有外部旧版审查。已用 `diff_analysis.py` 比较本轮初始与最终原理图分析，结果存于 `analysis/review/schematic-delta.json`：4 个铜测试焊盘从采购 BOM 排除，采购唯一物料项由 17 降至 13；原理图中仍保留全部 19 个元件，关键电路网络未改变。UC-002 提示仍存在，人工解释见下文。

本轮版图审查后增加 4 个 GND 回流过孔：USB_D− 两处换层和 UART_TX 两处换层的 RP-001 提示已消除，D1 地过孔不足提示也已消除。最终 EMC 自动风险分数由 83.5 升至 98.5（100 较好），仍保留 1 条警告；这是工具风险分数，不是合规测量。差异记录为 `analysis/review/emc-delta.json`。同时写入正式叠层，名义芯板厚由早期假设 0.930mm 改为 0.910mm；相应阻抗估算由 90.055Ω 更新为 89.859Ω。

### 电源树与完整关键网检查

```text
USB Type-C VBUS ─┬─ USBLC6 VBUS 钳位、C1 1µF
                └─ F1 PTC ─ +5V_FUSED ─ AP2112 VIN/EN
                                           │
                                          3.3V
                                           ├─ CH340C VCC16 + V3 pin4
                                           ├─ 电源指示灯 + 1kΩ
                                           └─ J2 pin1，外供预算 50mA
```

原生 XML 网表端到端核对记录为 `analysis/review-electrical-checks.json`，计算／检查脚本为 `analysis/review_electrical_checks.py`。覆盖 U1、U2、D1、J1、J2、F1、CC 下拉和 LED 支路。

- CH340C：1 GND，2 TXD→UART_TX，3 RXD→UART_RX，4 V3→3.3V，5 UD+→USB_D+，6 UD−→USB_D−，16 VCC→3.3V。
- WCH 第 4 页要求 3.3V 模式将 V3 与 VCC 连接；本设计按此处理。自建符号不是将未连接电源脚静默忽略。
- CH340C pin7 不使用；pin8 的实际功能为 OUT#，本地符号已修正；7–15 未用引脚悬空。原厂第 4 页原文为 “Unused I/O pins of CH340 should be suspended.”
- USB 数据脚不增加外部串联电阻，符合 WCH 第 4 页的直接连接要求；采用 CH340C 内部时钟，没有遗漏 CH340G 所需晶振。
- U2：1 VIN 与 3 EN 接 +5V_FUSED，2 GND，4 NC，5 VOUT 接 3.3V。EN 高电平使能与厂家第 2 页一致。
- D1：1/6 接 D+、3/4 接 D−、2 接 GND、5 接原始 VBUS；有内部 VBUS 钳位路径。

## USB 差分与回流

`analysis/usb-impedance.json` 采用移植自 KiCad 9 的 Kirschning/Jansen 耦合微带模型：线宽 0.750mm、边缘间隙 0.150mm、铜厚 0.035mm、参考介质 0.910mm、εr＝4.2，计算差分阻抗约 **89.859Ω**。

该模型假设连续背面参考地，不包含真实阻焊、焊盘、短颈、连接器及侧边铜。板厚 1.0mm 本身不足以确定阻抗。制板需注明 90Ω 差分控制（建议 ±10%），由板厂以实际 Dk、介质厚度和成品铜厚复核；如需调整线宽／间隙，必须更新设计后再导出。

| 最终几何 | D+ | D− |
|---|---:|---:|
| 0.750mm／0.150mm 均匀并行干线 | 5.000mm | 5.000mm |
| 全部 0.750mm 宽铜线，包括间隙变化的斜线过渡 | 5.707mm | 5.707mm |
| 全网表面铜线总长，包含 Type-C 分支 | 15.349mm | 16.083mm |
| A6／A7 接点到 U1 的表面路径 | 12.790mm | 13.158mm |
| B6／B7 接点到 U1 的表面路径 | 15.349mm | 15.283mm |

A 面两条路径表面长度差约 0.368mm。B 面表面差约 0.066mm，但 D− 的换向分支有两颗信号过孔；按两个 1mm 孔筒计入后，B 面几何路径差约 1.934mm。不能只报告 B 面表面差并称为完整传播匹配。这些是焊盘中心间铜路径估算，不包含芯片内部延迟、连接器传播与实测眼图。完整分段数据见 `analysis/usb-route-metrics.json`。

其余 0.15／0.30mm 线段是连接器、ESD 与引脚过渡，不宣称均匀 90Ω。均匀干线全部在顶层；底层设置禁止其他走线／过孔的参考区，顶层设置禁止侧边铺铜的区域。原生填充铜检查在干线下方以 0.1mm 网格采样 918 点，全部有背面 GND；这支持模型的回流假设，但不是场求解或阻抗认证。USB_D− 的两处信号过孔距最近地过孔约 0.987／0.962mm；UART_TX 两处约 0.760／0.786mm。

## 已知自动分析误报与人工解释

- **UC-002「J1 VBUS 缺少 ESD／TVS」**：本设计 D1 pin5 确实接 VBUS，ST 第 1 页明确列出 “ESD protection of VBUS”。因此不能按“完全没有 VBUS 钳位”报告。系统级 ESD 能力仍取决于布局与实际测试。
- TP1–TP4 是测试点，不是电容触摸电极；不套用触摸电极背面禁铜规则。
- `unconnected-(...)` 单点网络和 NC 标记是未使用引脚的显式处理，不作为漏接 UART 握手信号。
- USB 是 CH340C 的 Full-Speed 12Mbit/s；不把 USB 高速 480Mbit/s 的时序阈值直接套用为本板验收依据。
- **FD-001 基准点缺失**：没有板内 fiducial 属实，但工具因 Type-C 最小焊盘尺寸 0.30mm 而写成 “BGA/fine-pitch QFN present”，该描述不适用于本板。手工首板不因此失效；机贴需要装配厂安排拼板定位基准或另加板内标记。
- **TE-001 测试覆盖 4/23**：分母包括 12 个 NC 单点网。本板 4 个测试焊盘已覆盖全部 TTL 端口网络；不能将 17% 直接解释为只有 17% 功能可测。USB 仍需通过连接器与实物枚举测试。
- **EG-001 四条未保护信号**：其中两条未命名网实际是已 NC 的 SBU1／SBU2；另两条 CC1／CC2 确实没有独立 TVS。UART 也没有专用 ESD 阵列，不能把 USB 数据／VBUS 的保护扩大描述为所有接口都具备同等保护。
- **PM-002 边缘位置**：J1 courtyard 越出边界约 0.51mm 是 Type-C 插入口的预期边缘布局；J2 courtyard 距边约 0.45mm。仍需结合线束、外壳和分板工艺检查机械余量。
- **SU-001 两层相邻信号层**：这是双层板的一般限制；本设计通过均匀 USB 干线下方的实际背面地铜提供参考，不能仅凭层名 `signal` 判断该处没有参考面。
