# CH340C Type-C 转 3.3V TTL 转接板

设计日期：2026-11-10（新加坡时间）。版本：A。

快速查看：[原理图 PDF](exports/ch340-usb-ttl-schematic.pdf)、[PCB 3D 预览](exports/ch340-usb-ttl-3d.png)、[顶层布线](exports/ch340-usb-ttl-top.svg)、[设计审查](REVIEW.zh-CN.md)。

## 规格

| 项目 | 设计值 |
|---|---|
| PCB 尺寸 | 30×30 mm |
| 铜层／板厚 | 双层，1.0 mm |
| 元件面 | 全部在顶面，底面用于走线与地参考 |
| USB 接口 | Type-C 母座，USB 2.0 Full-Speed；独立 CC1／CC2 5.1kΩ Rd |
| USB-UART | CH340C，内部时钟，无外部晶振 |
| UART 电平 | 3.3V TTL；不是 RS-232 电平 |
| UART 连接器 | JST SUR，0.8 mm 间距，4PIN 卧插，SM04B-SURS-TF(LF)(SN) |
| 电源 | USB 5V → 500mA 保持电流 PTC → AP2112K-3.3 → 3.3V |
| 对外 3.3V 预算 | 建议不超过 50mA，保留 CH340C 与指示灯所需的 USB 电流预算 |
| 走线转角 | 使用 45°／斜线过渡，检查普通二度走线拐点不含 90° 转角 |
| USB 差分干线 | 目标 90Ω，名义线宽 0.75mm、边到边间距 0.15mm |

3.3V 的 50mA 是本设计对 USB 供电与热的使用预算，并不是独立的 50mA 电子限流器。LDO 本身额定电流不代表 USB 主机已授权相同的取电电流。

转角检查针对裸露走线的普通拐点；同网络焊盘或过孔铜盘内部的端接、分支连接不作为自由走线拐角，检查结果会保留这些端接位置供复核。

## 连接器定义

J2 焊盘编号与信号固定为：

| 引脚 | 信号 | 方向／用途 |
|---|---|---|
| 1 | 3.3V | 本板稳压输出 |
| 2 | TX | 本板发送，接目标设备 RX |
| 3 | RX | 本板接收，接目标设备 TX |
| 4 | GND | 共地 |

按 PCB 焊盘编号和 pin1 标记接线；不要将插头线束从正面与背面观察时的左右顺序混淆。匹配线束、端子和装配方向需按实际连接器选配。

只按 3.3V TTL 使用，不连接 RS-232 正负电压，也不默认对任意批次 CH340C 的 RX 输入施加 5V。

目标设备若独立供电，在 USB 拔出、本板断电时应停止驱动本板 RX，或另加具备断电保护的隔离／缓冲。当前板没有专用 UART 断电隔离，不能假定所有批次 CH340C 都能防止反向供电。

## 原理图要点

- CH340C 的 VCC（16）与 V3（4）同接外部 3.3V；两个供电脚附近均放置去耦。
- USB D+（5）／D−（6）直接连接 USB 数据网络，不增加串联电阻。
- 使用内置时钟；未使用 MODEM I/O 按 WCH 手册悬空并有 NC 标记。
- 本地符号 `CH340_USB_TTL:CH340C_3V3` 将 V3 标为本设计电源模式下的输入，并把旧标准库中的 pin8 NC 修正为 OUT#；pin8 仍未使用。
- USBLC6-2SC6 提供数据线与 VBUS 钳位；CC1、CC2 分别使用 5.1kΩ 下拉。
- AP2112 的 EN 接 VIN，输入与输出采用 4.7µF 标称电容，注意实际 DC 偏压后的有效电容应符合原厂至少 1µF 的要求。
- 带电源指示灯及 3.3V、GND、TX、RX 测试焊盘。

未提供 UART 硬件流控信号，软件串口应关闭 RTS／CTS、DSR／DTR 硬件流控。

## 90Ω 与制板叠层

本设计的主差分段按以下假设计算：FR-4 εr＝4.2、铜厚 35µm、顶层到背面地参考的介质厚度 0.910mm。使用 KiCad 9 的耦合微带模型，0.750mm／0.150mm 对应约 89.859Ω。

计算脚本：[scripts/usb_impedance.py](scripts/usb_impedance.py)；模型说明：[references/usb-impedance-model.zh-CN.md](references/usb-impedance-model.zh-CN.md)。

这不是板厂实测阻抗。投板时必须下单 **90Ω 差分阻抗控制，建议 ±10%**，并让板厂按实际材料 Dk、成品铜厚、阻焊与实际介质厚度复核。若板厂建议修改线宽／间距，需要同步更新 PCB 后再制造。

Type-C 换向引脚合并、器件焊盘处存在局部窄线和短连接；这些不能与均匀 90Ω 干线混为一谈。完整线路的过渡与长度信息见分析结果和设计审查报告。

## 文件

- `ch340-usb-ttl.kicad_pro`：KiCad 9 工程。
- `ch340-usb-ttl.kicad_sch`：原理图。
- `ch340-usb-ttl.kicad_pcb`：PCB。

- `exports/`：原理图 PDF／图像、PCB 预览和制造输出。
- `datasheets/`：已取得的原厂资料与镜像来源记录。
- `analysis/`：ERC、DRC、计算和 Happy 分析结果。
- `REVIEW.zh-CN.md`：设计审查与尚需确认事项。

用 KiCad 9 打开工程；保留整个目录，避免丢失本地符号和 3D 模型。制造文件应以最终导出的同一版本为准。

`exports/CH340C_USB_TTL_RevA_Gerber.zip` 只包含制造图层、钻孔及制板说明；完整工程压缩包另包含 BOM、顶层贴片坐标、审查记录和计算脚本。贴片坐标使用 KiCad 原生坐标约定及板左上辅助原点，Y 值可为负；装配厂应按坐标系解释，不能直接取绝对值。

原生工程可直接打开；`scripts/` 中的生成与分析辅助程序依赖本次准备的 `/workspace/pcb-tooling` 环境，不是脱离环境即可执行的独立安装包。修改原理图或重建布线后，需重新同步 PCB、检查并导出，不要将旧制造文件与新工程混用。

## 制造与验证范围

当前交付属于待实物验证的 PCB 设计。ERC／DRC、网表一致性和计算检查不能替代首板 USB 枚举、串口回环、负载、电源波形和阻抗测试。

本板的 3.3V 与指示灯直接随 USB 供电，没有独立的 USB 挂起负载门控；外部负载在主机挂起时的总取电需要单独管理，不能据此宣称已满足完整 USB 挂起电流合规要求。

JST／GCT／PTC 的独立厂家 PDF 在当前网络条件下未完整取得，封装采用 KiCad 官方标准库；投板前应以采购实际型号的厂家尺寸图和样品进行最终核对。原厂 CH340C、AP2112 与 USBLC6 资料已归档。

3D 预览使用归档的官方 KiCad 模型；JST SUR 和 PTC 的精确模型缺失，不应将预览作为它们的机械干涉校核。
