# 近距双夹 · 一次拾起两颗 M8 螺帽，单趟送入同一篮

两颗 0.993 g 螺帽在近站并排平放，MicroDuck 只低头闭喙一次，在起点同时夹稳两件，再带双件走过六个路标，向同一个篮释放。名义横向中心距 **17.3–26 mm**，前后错位 ±2 mm，另对每颗各轴独立加 ±1 mm 扰动并随机偏航。两件在这轮实验开始时已经位于喙宽以内。

[观看第二版完整回合（2 倍速）](replay.mp4)。种子 48531501 是按登记顺序的首个成功回合（S0、20 ms），5.08 秒携双件出发，48.60 秒开始松喙，54.10 秒完成。两件最终在篮内共同承托 4.91 秒。第二版登记首例 48531500 起点同步夹取失败，其记录计入下表。

## 从双夹到整屋

1. **开发单次双夹。** 名义间距 17.3 mm，相同 64 个起点分别尝试四组身体动作。默认拾取为 57/64，选中的身体参数为 64/64。固定该动作把物理步由 5 ms 改成 2.5 ms，同一批起点变为 62/64。将间距扩至 17.3–26 mm 后，逐件观察上下垫力和离地时刻，调整头偏航、俯仰与闭喙相位。另 192 个新起点做到 192/192，只计起点同步夹持。[单次拾取开发记录](pickup-development.json)
2. **连续执行整屋任务。** 两颗都要同时接触上下喙垫，最低点至少离地 20 mm，无外部承托，共同持稳至少 2 秒方可出发。运输中持续监测接触、掉件和碰撞。终点需要两件共同在篮中稳定受托至少 2 秒，鸭子退开站稳。地图、基座定位和预演所需物理状态在仿真中可读。
3. **回放第一版失败。** 第一版 S1、0 ms 有三例失败，其中一次 B 短暂停在篮沿。锁定相同篮前状态，分别要求候选投放预测能承托 0.16、0.35、0.50、0.75 秒。0.75 秒筛选让这个失败起点最终共同承托 4.635 秒。加入头偏航备选动作以处理另外两次漏夹，最终把第二版控制器重新冻结，换另一批种子做整屋验收。
