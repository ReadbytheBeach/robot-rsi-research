# 从地面叼起短瓜段，绕三处障碍投入黑筐

MicroDuck 在 MuJoCo 里完成了 309/320 个冻结回合（96.56%），达到整体验收的 95% 目标。原生 PhysX 用相同 320 个起点时全部止于拾取。两者之间最早能观察到的任务差异发生在喙垫带载抬升时。[正式首例的原速录像](replay.mp4) · [分组统计和接触测量](evidence.json)

## 任务与控制

地面上的瓜段使用长 123 mm、直径 17 mm、质量 18 g 的胶囊碰撞体。鸭子用上下喙垫夹起瓜段，离地至少 20 mm 并连续持稳 2 秒，沿已知路线过六个路标、绕三处障碍，在低沿开口黑筐前释放瓜段。终点要求瓜段完整位于筐内、与喙和地面分离、连续获筐底承托至少 2 秒，鸭子后退并站稳。

拾取、步行和站稳分别沿用已有的 `alpha_ground_pick.onnx`、`alpha_walking.onnx` 和 `velstand.onnx`。本轮搜索调整了拾取时的腿和头颈姿态、闭喙节拍及筐前对位参数。Python 控制器单独驱动下颌，根据地图、机器人和物体仿真状态以及接触力切换阶段。

## 留出验收与双引擎差异

每档指令延迟包含 L0–L3 四种布局，每种布局 40 例。瓜段起点各轴在标定位置附近扰动 ±0.8 mm，偏航扰动 ±0.012 rad。成功率适用于这个近站范围和上述代理几何，整根黄瓜、原始 USD 篮筐和实机尚待验收。[逐种子配对结果](paired-seeds.csv)

| 额外指令延迟 | 回合数 | MuJoCo 完整成功 | 原生 PhysX 完整成功 |
| --- | ---: | ---: | ---: |
| 0 ms | 160 | 158（98.75%） | 0 |
| 20 ms | 160 | 151（94.38%） | 0 |
| 合计 | 320 | 309（96.56%） | 0 |

原生 PhysX 有 292/320 个回合出现双侧喙垫受力，带载净抬升达 20 mm 的回合数为零。正式首例 `935000` 的配对记录中，到 4.125 秒时两个引擎的鸭子本体质心高度都约 138–139 mm。此时 MuJoCo 中瓜段质心高 209.3 mm，两侧喙垫力分别约 4.70 N 和 5.05 N；PhysX 中瓜段质心仍高 8.5 mm，两侧力均为 0 N。这个测量把问题定位到接触后形成并维持夹持的阶段，具体的材料或驱动参数原因还有待验证。[冻结成绩与同一时刻的原始读数](evidence.json)

## 看录像与复核

视频为 L0、0 ms、种子 `935000` 的完整 MuJoCo 回放，保留原画幅和原速。0.98 秒首次双侧接触，2.13 秒瓜段离地 20 mm，4.125 秒完成持续夹持，19.22 秒开始释放；24.30 秒验收时，瓜段已连续获筐底承托 4.715 秒。[完整录像](replay.mp4)

本目录提供视频、320 例配对 CSV 和从冻结记录提取的 JSON。JSON 包含拾取参数、路线参数、两引擎分组成绩、原始文件的工作区相对路径与 SHA-256。完整重跑需要原工程的机器人模型与网格、三份 v7 ONNX、相邻的路线代码和冻结控制器。本机验证版本为 Python 3.12.3、MuJoCo 3.10.0、ONNX Runtime 1.24.4。

在具备这些依赖的 `microduck_e-skin` 工程根目录，激活原仿真 Python 环境后运行以下命令。入口会核验依赖文件，并把注册种子逐字段与归档对照。完整环境和映射说明见原工程的 `experiments/simready-beak-delivery/部署.md`。

```bash
cd experiments/simready-beak-delivery
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
OUT=$(mktemp -d)
python mj/run_floor_delivery.py --seed 935000 --layout L0 --delay-ms 0 --out "$OUT/run"
python evidence/com.py "$OUT/run/trace.npz" "$OUT/com" --title "MicroDuck floor delivery, seed 935000"
```

预期单例结束时刻为 24.30 秒。`result.json` 给出验收结果，`trace.npz` 保存逐物理步记录，质心导出工具生成本体、瓜段和组合质心的图与数据。
