# 动作幅度粗调与腿部反馈精调

MicroDuck 模仿 NVIDIA 的抬脚舞段时，难点是右脚抬起前后，左脚能否持续独立承重，同时让机器人落地后继续跳完第二遍。2026 年 11 月 23 日的这组实验比较了保留原幅度后直接精调，以及先将头颈幅度降到 80% 再精调两种做法。

## 做法

先用相同的开发种子跑 84 次回合，比较七组头颈和腿部幅度。再分别从原幅度和头颈 80% 出发，用回合奖励和交叉熵法搜索八个腿部反馈及相位参数。每个起点有 150 个搜索回合和 63 个复筛回合，单关节附加指令限制在 0.10 rad。最终冻结四套方案，在相同的六个新种子、四种工况上执行两遍连续动作。每个策略与工况有 6 个回合、12 个计划右拍。[两组冻结参数与模型哈希](parameters.json)

## 结果

| 板端滤波模拟加 20 ms 延迟 | 跳完两遍 / 6 | 峰值仅左脚接地且右足高至少 3 mm / 12 | 连续覆盖目标前后各 100 ms / 12 |
|---|---:|---:|---:|
| H0 基线 | 0 | 0 | 0 |
| 仅头颈缩至 80% | 0 | 0 | 0 |
| 保留原幅度再精调 | 6 | 1 | 0 |
| 头颈缩至 80% 再精调 | 0 | 2 | 0 |

直接精调的六次均跳完两遍，但整段最大水平漂移为 150–196 mm，超过 100 mm 目标，而且 11/12 个右拍峰值仍只有右脚着地。在原生 MuJoCo 和 PhysX 中，仅缩头颈各多得到 1 个连续 100 ms 的正确支撑拍。四个策略在四种工况都未完成连续 200 ms 的目标。板端滤波与延迟均在软件中模拟。[四工况完整冻结统计](results.json)

[固定种子 491060，两遍原速本地仿真录像](replay.mp4)。从左到右依次是 H0、仅粗调、原幅度直接精调、粗调后精调。画面保留终止时刻和定格，头两栏提前结束时可继续观察第三栏的落脚与漂移。发布版裁出本地四栏，保留全部 286 帧，15 fps，约 19.07 秒。

原实验工作区入口为 `experiments/soma-amplitude-curriculum-20261123/`。在该目录内，`test/registration.json` 列出固定种子和时间窗，`test/delay/direct/491060.json` 与同名 `.npz` 对应片中第三栏的整段物理回放。`test/trial.py` 运行一套已冻结策略的四工况评估，`test/score_trials.py` 从记录计分。本目录提供可直接观看的录像、统计和参数；重新运行物理实验还需要原工作区的模型、机器人资产及仿真环境。
